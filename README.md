# VR Monitor

Android-приложение для использования смартфона в качестве экрана VR-гарнитуры. При подключении USB-устройства автоматически гасит подсветку и блокирует тачскрин, сохраняя при этом видеосигнал для очков. При отключении — восстанавливает всё обратно.

Протестировано на **OnePlus 15 (Android 16, KernelSU)**.

---

## Что делает

- Определяет подключение любого USB-устройства (OTG)
- Ждёт настраиваемое время (чтобы успеть нажать нужные кнопки на экране)
- Гасит подсветку через прямую запись в sysfs — дисплей продолжает передавать сигнал в очки
- Блокирует тачскрин через `/sys/class/input/inputX/inhibited`
- Устанавливает таймаут экрана в `∞` (экран не засыпает во время просмотра)
- При отключении USB восстанавливает яркость в авто-режим и устанавливает заданный таймаут
- Аварийный сброс через кнопку в уведомлении (или просто отключите USB)

---

## Требования

- Android 8.0+ (minSdk 26)
- **Root-доступ** — KernelSU или Magisk
- USB OTG (для подключения гарнитуры или любого другого USB-устройства)

---

## Установка

1. Скачайте APK из [Releases](https://github.com/davnozdu/vr-usb-monitor/releases)
2. Установите на устройство
3. Откройте приложение
4. Выдайте root-права в KernelSU Manager → SuperUser → VR Monitor → **Разрешить всегда**
5. Убедитесь что строка Root отображает **"Root: доступен"**

---

## Настройки

| Параметр | По умолчанию | Описание |
|---|---|---|
| Выключать подсветку | Вкл | Гасит экран через sysfs, сигнал для очков остаётся |
| Блокировать тачскрин | Вкл | Запись `1` в `/sys/class/input/inputX/inhibited` |
| Задержка перед блокировкой | 15 с | Время на нажатие кнопок после подключения (0–120 с, шаг 5 с) |
| Таймаут экрана после отключения | 15 с | Какой таймаут установить когда гарнитура отключена (15/30/45/60 с) |

## Как работает подсветка

Android ограничивает минимальную яркость через своё API — даже при `screen_brightness = 0` на экране остаётся едва заметное свечение. Приложение обходит это ограничение:

1. Отключает авто-яркость: `settings put system screen_brightness_mode 0`
2. Устанавливает яркость через Android API: `settings put system screen_brightness 0`
3. Пишет напрямую в sysfs: `echo 0 > /sys/class/backlight/panel0-backlight/brightness`
4. Повторяет запись через 5 секунд — чтобы display manager не перебил значение

При отключении USB яркость возвращается в **авто-режим**.

## Сборка

```bash
git clone https://github.com/davnozdu/vr-usb-monitor.git
cd vr-usb-monitor
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

CI собирает APK автоматически при каждом push в `main` (GitHub Actions).

## Разрешения

- `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_SPECIAL_USE` — фоновый сервис мониторинга
- `RECEIVE_BOOT_COMPLETED` — автозапуск после перезагрузки

Root-команды выполняются через `su -c` (KernelSU / Magisk).
